# Sources Register

Primary/official sources are preferred. Security and transport conclusions must be revalidated at implementation/release time.

- OpenAI developer documentation — MCP/connectors and Secure MCP Tunnel.
- Model Context Protocol specification and official Rust SDK repository.
- Microsoft Learn — Windows Job Objects.
- Microsoft Learn — CreateRestrictedToken/security APIs.
- Microsoft Learn — reparse points/filesystem behavior.
- Microsoft Sysinternals RAMMap and Windows PoolMon tooling.
- ELITEAYOTO/OpticCode — process runner, policy and transaction implementation inspected during planning.
- DesktopCommanderMCP public repository/issues/releases — comparative evidence, not a design authority.

Research reports supplied during planning are inputs, not normative specifications. Claims become canonical only after verification or explicit status marking.
